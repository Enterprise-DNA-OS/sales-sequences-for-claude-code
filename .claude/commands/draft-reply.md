---
description: Draft a reply to a prospect's latest message, picking up what they said.
---

```bash
npm run seq -- prospect <prospect> --json
npm run seq -- draft-reply <prospect>
```

Read their history first. Answer what they asked in the first sentence, then one clear next step. Edit the draft file in place. Never promise pricing, terms or dates the operator has not given you.

Every answer starts from the CLI output. Use the record codes it prints. Never answer about a prospect, account or rep from memory, and never invent a record or a reply. If a name matches more than one record, show the candidates and ask. Nothing here sends: drafts go to drafts/ and a person sends them from their own mailbox.

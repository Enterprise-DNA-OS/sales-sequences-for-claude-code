description: Replies nobody has answered yet, oldest first. The most valuable list in outbound.
---

```bash
npm run seq -- replies --json
```

Show who replied, what they said, which rep owns them and how many days it has waited. Positive replies first. For each, suggest the next move in one line and offer /draft-reply. A reply sitting for more than a day is the first thing in /weekly-review.

Every answer starts from the CLI output. Use the record codes it prints. Never answer about a prospect, account or rep from memory, and never invent a record or a reply. If a name matches more than one record, show the candidates and ask. Nothing here sends: drafts go to drafts/ and a person sends them from their own mailbox.

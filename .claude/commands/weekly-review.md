---
description: The Monday review for the sales lead, written from compliance, replies, overdue steps, meetings, sequence results, rep activity and quiet accounts.
---

```bash
npm run seq -- weekly-review --json
```

Write it in five short parts: 1. Compliance (breaches by name). 2. Replies waiting and meetings needing an update. 3. Each rep's week: touches, connects, replies, meetings booked, overdue steps. 4. Sequences: which earn meetings and which do not, with numbers. 5. Quiet tier A and B accounts nobody is working. Finish with who acts on each, and nothing else. Save to drafts/weekly-review-YYYY-MM-DD.md if the operator wants to share it.

Every answer starts from the CLI output. Use the record codes it prints. Never answer about a prospect, account or rep from memory, and never invent a record or a reply. If a name matches more than one record, show the candidates and ask. Nothing here sends: drafts go to drafts/ and a person sends them from their own mailbox.
